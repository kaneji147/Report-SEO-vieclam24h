1 Cấu Hình Kết Nối Dữ Liệu

Do tab Summarize không ở dạng bảng phẳng, hãy dùng phương pháp Named Ranges (Dải ô có tên) trên Google Sheets hoặc tạo các Data Source riêng trong Looker Studio với Option "Use first row as headers":

  • Tiến độ tháng: Summarize!B27:I29
  • Hiệu suất PIC: Summarize!K25:S30
  • Nhuận bút: Summarize!B37:F43
  • Từ khóa chi tiết: Summarize!H41:M254
2 Trường Tính Toán (Calculated Fields)

Tạo thêm các chỉ số phái sinh trên Looker Studio để nâng cao năng lực giám sát:

// Tỷ lệ Xuất bản / Duyệt
SUM(Đã Published) / SUM(Đã duyệt)
// Tỷ lệ Lỗi Bản Thảo Đầu
SUM(Fix 1) / SUM(Đã Done)
3 Bố Cục & Trải Nghiệm UX

Áp dụng nguyên tắc thiết kế dashboard chuyên nghiệp:

  • Top Banner: Đặt Scorecards tổng hợp cấp cao nhất (Tổng bài, Đã duyệt, Đã đăng).
  • Mid Section: Đặt Biểu đồ cột nhóm so sánh xu hướng tiến độ và biểu đồ chất lượng.
  • Bottom Section: Đặt bảng chi tiết từ khóa có tính năng Search và bộ lọc tương tác.
